# Namma Space: Sample Test Dataset Directory
**Techfest 2026-27, IIT Bombay — Challenge Track: Namma Space**

This directory contains turnkey sample test data so judges and reviewers can test the entire pipeline end-to-end without needing to supply external videos.

---

## 📁 Directory Structure

* **`sample_indoor_walkthrough.mp4`**: 
  * A continuous smartphone-style indoor video walkthrough (720p @ 30 FPS).
  * Simulates a steady gimbal walkthrough following our Standard Operating Procedure (SOP): Reception Foyer $\to$ Executive Lounge $\to$ Boardroom Suite $\to$ Workstation Pods $\to$ Panoramic Window Facade $\to$ Loop closure.
* **`create_sample_walkthrough_video.py`**:
  * Automated generator script used to synthesize/re-render the test walkthrough video.
* **`test_keyframes/`**:
  * Directory containing 16 multi-angle keyframes pre-extracted from the indoor tour.
* **`extracted_frames/`**:
  * Output directory generated by `pipeline/extract_frames.py` containing keyframes that passed Laplacian variance sharpness filtering.
* **`sample_manifest.json`**:
  * Sharpness scores, frame timestamps, and simulated FOV metadata.
* **`video_sfm_output/`**:
  * Output directory generated by `pipeline/colmap_sfm.py` containing solved camera poses (`transforms.json`) and sparse point cloud (`sparse_points.ply`).

---

## 🚀 How to Run the Pipeline on the Sample Video

```bash
# 1. Extract sharp keyframes from the sample walkthrough video
python pipeline/extract_frames.py --video sample_data/sample_indoor_walkthrough.mp4 --output sample_data/extracted_frames --fps 2.0 --blur-threshold 50.0

# 2. Run Structure-from-Motion (SfM) camera pose solving
python pipeline/colmap_sfm.py --images sample_data/extracted_frames --output sample_data/video_sfm_output

# 3. Explore the corresponding 3D digital twin in the Web Viewer
cd web-viewer
npm run dev
# Click "Play Demo Tour" to watch the automated video walkthrough tour!
```
